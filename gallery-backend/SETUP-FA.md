# راه‌اندازی گالری مشترک تصاویر (Supabase — رایگان)

گالری «تصاویر» عکس‌هایی که همه کاربران در چت می‌فرستن رو نشون میده.
چون سایت روی GitHub Pages ـه (فقط فایل، بدون سرور)، برای گالری مشترک یه
بک‌اند رایگان لازم داریم. کل کار حدود ۵ دقیقه طول می‌کشه.

## قدم ۱ — ساخت پروژه رایگان

1. برو به [supabase.com](https://supabase.com) و با گیت‌هاب یا ایمیل ثبت‌نام کن.
2. دکمه **New project** رو بزن.
3. یه اسم بده (مثلاً `aichat-gallery`)، یه رمز برای دیتابیس انتخاب کن،
   نزدیک‌ترین منطقه (Region) رو انتخاب کن و **Create new project** رو بزن.
4. یکی دو دقیقه صبر کن تا پروژه آماده بشه.

## قدم ۲ — اجرای اسکیما

1. از منوی سمت چپ برو به **SQL Editor**.
2. **New query** رو بزن.
3. کل محتوای فایل `supabase-schema.sql` (همین پوشه) رو کپی و اونجا بچسبون.
4. دکمه **Run** رو بزن. اگه خطا نداد یعنی جدول و باکت ساخته شدن.

این اسکیما چیکار می‌کنه:
- جدول `gallery` برای آدرس عکس‌ها
- باکت `gallery` برای ذخیره فایل‌ها (عمومی، حداکثر ۳۰۰ کیلوبایت، فقط JPEG)
- دسترسی: همه می‌تونن ببینن و عکس بفرستن (بدون لاگین)

## قدم ۳ — برداشتن کلیدها

1. از منوی سمت چپ برو به **Project Settings** (آیکون چرخ‌دنده) → **API**.
2. این دو مقدار رو کپی کن:
   - **Project URL** (مثل `https://xyz.supabase.co`)
   - **anon public** key (کلید طولانیه — همون `anon`، نه `service_role`!)

## قدم ۴ — وصل کردن به برنامه

1. توی برنامه، وارد **پنل مدیر** شو.
2. تب **گالری مشترک** رو باز کن.
3. آدرس و کلید رو بچسبون، **ذخیره** رو بزن، بعد **تست اتصال**.
4. اگه سبز شد، تمومه! از این به بعد هر عکسی که هر کاربری در چت بفرسته
   (به‌صورت بندانگشتی و کم‌حجم) وارد گالری مشترک می‌شه.

## نکته‌های مهم

- **حریم خصوصی:** عکسی که کاربر در چت می‌فرسته برای همه قابل دیدنه.
  قبل از نمایش گالری، برنامه فقط **یک‌بار** از بیننده اجازه می‌گیره.
- **حجم:** عکس‌ها قبل از آپلود به حداکثر ۵۱۲ پیکسل و فرمت JPEG کم‌حجم
  تبدیل می‌شن تا فضای رایگان زود پر نشه.
- **مدیریت:** حذف عکس‌ها از داشبورد Supabase → Storage → باکت `gallery`
  یا Table Editor → جدول `gallery` انجام می‌شه.
- سهمیه رایگان Supabase برای این مصرف خیلی زیاده و به این زودی‌ها تموم نمی‌شه.
