# 🤖 چت‌بات هوش مصنوعی چند API

یه چت‌بات وب فارسی و راست‌چین که به چند ارائه‌دهنده‌ی هوش مصنوعی (سازگار با OpenAI API) وصل میشه و می‌تونی بینشون جابه‌جا بشی.

## ✨ امکانات

- اتصال به چند API: **OpenAI**، **Google Gemini**، **Groq**، **Cerebras**، **Mistral**، **Together AI**، **OpenRouter**، **DeepSeek**، **xAI (Grok)** + گزینه‌ی **سفارشی** برای هر سرویس OpenAI-Compatible دیگه
- ⚡ **اتصال هوشمند**: کلید API رو بچسبون؛ ارائه‌دهنده و مدل‌ها خودش تشخیص داده می‌شن
- 🎛 **سوییچر مدل** بالای صفحه: جابه‌جایی سریع بین ارائه‌دهنده‌ها و مدل‌ها بدون باز کردن تنظیمات
- پاسخ **استریمینگ** (زنده) با دکمه‌ی توقف
- رندر **مارک‌داون** + هایلایت کد، با بج مدل/ارائه‌دهنده روی هر جواب
- زیر هر جواب: **کپی**، **تلاش مجدد**، 👍/👎، **🔊 خواندن با صدا** و **سؤال‌های پیشنهادی بعدی**
- ➕ **پیوست چندرسانه‌ای**: فایل، عکس از گالری، دوربین، ویدیو (با استخراج خودکار فریم) و **ضبط صدا**
- 🖼️ **بینایی (Vision)**: تصویرها مستقیم برای مدل‌های بینایی فرستاده می‌شن؛ متن فایل‌های متنی هم به پیام اضافه می‌شه
- 🎤 **گفتار به متن** زنده و فارسی (رایگان، بدون نیاز به کلید) + رونویسی خودکار صدای ضبط‌شده با Whisper (اگه کلید OpenAI داشته باشی)
- 🔖 **کتابخانه**: با دکمه‌ی نشانک زیر هر پاسخ، متن‌ها و کدهای مهم رو ذخیره کن؛ جستجو، فیلتر متن/کد، کپی، باز کردن گفتگو و حذف
- ⏰ **زمان‌بندی‌شده**: زمان‌بند سمت کاربر برای پیام‌های تکراری — یک‌بار / هر روز / هفتگی؛ با «الان اجرا کن»، توقف/فعال‌سازی و مقصد گفتگوی جدید یا مشخص (تسک‌ها فقط وقتی سایت بازه توی مرورگرت اجرا می‌شن)
- 🧮 **افزونه‌ها (ابزارهای سریع سمت کاربر، بدون کلید API)**: ماشین‌حساب با توابع ریاضی (پارسر امن بدون eval)، تبدیل واحد (طول/وزن/دما/داده/زمان)، فرمت‌کننده و اعتبارسنج JSON، و تاریخ شمسی/میلادی + ساعت مناطق مختلف دنیا
- 📥 **خروجی Markdown** از هر گفتگو
- سایدبار گفتگوها: ساخت، **تغییرنام**، حذف، **جستجو** و گروه‌بندی بر اساس تاریخ
- 🎁 راهنمای داخلی ۶ API رایگان و قوی (Gemini، Groq، Cerebras، Mistral، OpenRouter، Together AI)
- 🔐 **حساب مدیر** (ایمیل + رمز): آمار استفاده، کنترل نمایش ارائه‌دهنده‌ها برای مهمان‌ها، بکاپ/بازیابی، پاک‌سازی
- مهمان‌ها بدون ورود و با کلید خودشون از سایت استفاده می‌کنن
- ذخیره‌ی جداگانه‌ی کلید API برای هر ارائه‌دهنده (فقط توی مرورگر خودت، با localStorage)
- رابط فارسی راست‌چین با فونت وزیرمتن؛ **تم پیش‌فرض «چت‌جی‌پی‌تی»** (روشن و مینیمال به سبک اپ ChatGPT) + ۶ تم رنگی دیگه با انیمیشن‌های نرم، و **لوگوی واقعی** هر ارائه‌دهنده
- 📱 **دراور کناری** به سبک اپ ChatGPT: منوی همبرگری، جستجو، آیتم‌های ناوبری، بخش **📌 سنجاق‌شده** و **🕘 اخیر**، و دکمه‌ی آبی «گفتگوی جدید»
- 🏠 صفحه‌ی خوش‌آمد مینیمال با **ردیف‌های پیشنهادی** آیکون‌دار (مثل اپ)
- 🔒 کلید API فقط در مرورگر خودت می‌مونه و جز به ارائه‌دهنده‌ای که خودت انتخاب می‌کنی به هیچ‌جا ارسال نمی‌شه

## 📦 نسخه‌ها

- **v6.18**: پوسته‌ی دقیق‌تر اپ ChatGPT — سوییچر مدل به‌صورت پیل آبی «Get Plus» کنار منو، صفحه‌ی خوش‌آمد با ردیف‌های پیشنهاد در پایین (مثل صفحه‌ی اصلی اپ)، و دایره‌ی آواتار کاربر کنار دکمه‌ی گفتگوی جدید در پایین دراور
- **v6.17**: تکمیل سه قابلیت دراور — کتابخانه (ذخیره پاسخ/کد)، زمان‌بندی‌شده (تسک‌های یک‌بار/روزانه/هفتگی با اجرا خودکار) و افزونه‌ها (ماشین‌حساب امن، تبدیل واحد، فرمت‌کننده JSON، تاریخ و زمان) + اعلان toast + رفع باگ هایلایت کد (اسکریپت CDN اشتباهی بود و در مرورگر اجرا نمی‌شد) + تکمیل آیکون‌های گم‌شده‌ی UI
- **v6.16**: رفع خطای 400 «reduce the length» با سقف ۴۰ هزار کاراکتر برای فایل‌های پروژه و کوتاه‌کردن خودکار تاریخچه تا بودجه‌ی ۱۲۰ هزار کاراکتری API

## 🚀 دیپلوی روی Railway

۱. این ریپو رو به گیت‌هاب پوش کن.
۲. توی [Railway](https://railway.app) پروژه‌ی جدید بساز و گزینه‌ی **Deploy from GitHub repo** رو انتخاب کن.
۳. همین ریپو رو انتخاب کن — ریل‌وی خودش `Dockerfile` رو پیدا می‌کنه و بیلد می‌گیره.
۴. از بخش Settings یه دامنه‌ی عمومی (Generate Domain) بگیر. تمام!

> نکته: کلیدهای API سمت کاربر (توی مرورگر) ذخیره می‌شن و نیازی به تنظیم Environment Variable نیست.

## 🖥 اجرای محلی

```bash
cd ai-chatbot
python3 -m http.server 8080
```

بعد باز کن: http://localhost:8080
